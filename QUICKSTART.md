# 🚀 Quick Start - 5 Pasos

## Paso 1: Instalar (2 min)

```bash
cd /Users/macbook/Documents/DEV/VisualBoost
npm install
```

## Paso 2: Ejecutar (1 min)

```bash
npm run dev
```

Abre: http://localhost:3000

## Paso 3: Personalizar (10-15 min)

Edita `src/data/services.ts`:

- Cambia planes de precios
- Actualiza servicios
- Personaliza testimonios
- Edita FAQ

Edita `src/components/ContactForm.tsx`:

- Tu email
- Tu WhatsApp
- Tu teléfono

Edita `tailwind.config.js`:

- Colores primaryy accent

## Paso 4: Build (1 min)

```bash
npm run build
```

## Paso 5: Deploy (5 min)

**Opción A: GitHub Pages (Recomendado)**
```bash
git add .
git commit -m "Initial commit"
git push
```

**Opción B: Vercel**
```bash
npm install -g vercel
vercel
```

**Opción C: Netlify**
- Ve a netlify.com
- Conecta tu repositorio GitHub
- Deploy automático

## 🆘 Problemas Comunes

### "npm: command not found"
→ Instala Node.js desde https://nodejs.org

### "Port 3000 already in use"
→ `npm run dev -- --port 3001`

### "Build error"
→ `npm run build` locallt para ver el error

### "No veo cambios"
→ Ctrl+Shift+R (hard refresh)
